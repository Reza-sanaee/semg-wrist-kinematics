# sEMG Wrist Kinematics Estimation with CNN-LSTM

Bachelor's project exploring a CNN-LSTM pipeline on NinaPro DB2 for normalized roll, pitch, and yaw surrogate trajectories derived from movement labels.

## Technical highlights

- Organized preprocessing, training, inference, saved-prediction evaluation, and an interactive 3D demonstration.
- The supplied experiment uses movement-label-derived targets rather than measured continuous glove angles. Evaluation and split limitations are documented in TECHNICAL_NOTES.md.
